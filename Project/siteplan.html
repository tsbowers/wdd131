Utah Vacation Planner – Site Plan

WDD 131 – Project Planning Document

Site Name

Utah Vacation Planner

This name was chosen because the site helps users explore Utah's best destinations and plan their adventure with a bucket list and interactive map.

Site Purpose

The purpose of this website is to be a simple trip planner. for Utah visitors. The site will offer:

  • Highlights of Utah's major nature destinations
  • A customizable bucket list that can be saved
  • An interactive map to plan routes and combine locations
  • Tips for outdoor travel in Utah

Scenarios

  • “What are the must-see places if I'm visiting Utah for the first time?”
  • “How can I build and save my own Utah outdoor adventure bucket list?”

Color Scheme

The website will use a National Park–style ranger color palette:

  • Primary (Headings): Ranger Green – #4A5E4D
  • Secondary (Borders/Highlights): Ranger Hat Brown – #8A6E4B
  • Accent: Sagebrush – #A3A380
  • Background: Sand Dune – #EDE6D6
  • Text: Dark Spruce – #2C3A32

This site plan document uses these colors in the header, borders, background, and headings.

Typography

  • Heading Font: Merriweather (serif, traditional outdoor guide feel)
  • Body Font: Open Sans (clean and readable)

These fonts appear throughout this document.
